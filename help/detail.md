### 使い方（くわしく版）

#### 1. ログイン
- 先生から渡された **ID** と **パスワード** を入れます。ID は大文字・小文字を区別しませんが、**パスワードは区別します**。
- ID はメールアドレスの形のことがありますが、メールではありません。パスワードは**この自習室だけで使う専用のもの**で、Google などのパスワードとは別です。
- 同じ ID で **5回続けて間違えると、10分間入れなくなります**（先生にも知らせが届きます）。待ってからやり直してください。
- 登録されていても、**開始日の前**は入れません。その場合は、使える日が画面に出ます。
- パスワードは、ご本人とご家庭の中だけでお使いください。他の人に教えないでください。

#### 2. 入室する（ロビー）
- ログインすると「ようこそ、○○ さん」と出ます。「🚪 入室する」を押すと、勉強の時間が始まります。
- その日、すでに自習室に来た人がいれば「今日はここまでに ○○さん も来てるよ」と出ます。**あなたの名前も、同じ日にあとから来た人には見えます。** 来ていない人の名前は、出ません。
- 入室せずに終わりたいときは、「ログアウト」を押します。

#### 3. 集中する
- 「🔥 いま、集中中。」の画面になります。カメラの許可を聞かれたら「許可」を選ぶと、**手元が自分の画面に映ります**。
- **見守りのしくみ**：許可したカメラから、**入室の数秒後と、そのあと10分おきに、静止画（写真）が1枚ずつ、先生の連絡用の場所に届きます。** 動画（映像の流れ）が送られたり、録画されたりはしません。先生は、その静止画で、手元の様子を見守ります。
- 手元（ノートや問題集）が映るように、カメラの向きを整えてください。顔を映す必要はありません。
- カメラを許可しなくても、勉強と報告はできます。その場合、静止画は届きません。
- **ページを再読み込みしたり、タブを閉じたりすると、ログイン画面に戻ります。** 書きかけの報告は消えるので、気をつけてください。

#### 4. 報告して退室する
1. 「🚪 集中を終了する（成果報告へ）」を押します。
2. **やってみたこと**に、何の教材のどこを、どうしたか（解いた・丸付けした・説明した…）を書きます。
3. **てこずったこと**に、気づいたこと・発見・次はどうしたいか を書きます。うまくいった日も、いちばんあやしかったところを書いてみてください。ここが一番大切です。
4. 「🚀 報告して退室する」を押します。どちらも空のままだと送れません。

#### 5. 報告のあと
- 「アシスタント」から返事が届きます。アシスタントは**AI（人工知能）**で、先生本人ではありません。あなたの報告を読んで、考えるヒントになる質問を返します。
- 今日の滞在時間が出ます。「もう一度入室する」でまた勉強でき、「完全に退室する」で終わりです。

#### 6. 書いた内容は、だれに届くの？
- **先生**：入室・退室のお知らせ、手元の静止画（10分おき）、書いた報告（アシスタントの返事つき）が、先生の連絡用の場所に届きます。静止画は、その場所に残ります。
- **AI（Google の Gemini）**：返事を作るために、報告の文章が送られます。
- **他の生徒**：見えるのは「今日来た」ことだけです。報告の中身や、手元の静止画は見えません。

#### 7. 困ったとき
| こんなとき | こうしてみてね |
|---|---|
| ログインできない | ID と パスワードを確認。大文字・小文字、全角・半角、前後の空白に注意。続けて間違えると10分ロックされます |
| 「このIDは○月○日から使えるよ」と出た | まだ開始日の前です。その日からお使いください |
| 開くのにとても時間がかかる | しばらく使われていないと、起動に30〜40秒かかることがあります。少し待ってください |
| カメラが映らない | ブラウザのカメラ許可を確認してください。映らなくても勉強と報告はできます（その間、静止画は先生に届きません） |
| 報告を書いている途中で、ログイン画面に戻った | ページを開き直すと、ログイン画面に戻ります。もう一度ログインして、書き直してください |
| ログアウトしたい | 入室前なら「ログアウト」、報告のあとなら「完全に退室する」を押します |
| それでもだめ | 先生に連絡してください |
